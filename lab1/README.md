## Завдання (варіант 1):

Визначити ті рядки, довжина яких менша (більша) середньої.

## Інструкція з локального запуску:

1. Склонуйте репозиторій
```bash
git clone https://github.com/lestaplus/java-labs.git
```

2. Скомпілюйте та запустіть із кореня проєкту
```bash
javac lab1/*.java
java lab1.Main
```
