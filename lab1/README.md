# Лабораторна робота №1: Робота з циклами, масивами та рядками в Java

## Завдання (варіант 1):

Визначити ті рядки, довжина яких менша (більша) середньої.
На вхід поступає масив String. На виході – масив String.

## Інструкція з локального запуску:

1. Склонуйте репозиторій
```bash
git clone https://github.com/lestaplus/java-labs.git
```

2. Перейдіть до теки лабораторної роботи
```bash
cd java-labs/lab1/src
```

3. Скомпілюйте та запустіть програму
```bash
javac Main.java StringAnalyzer.java
java Main
```
