# Лабораторна робота №10: Reflection, Logging, Internationalization

## Завдання 1:

**Робота з рефлексією**

Напишіть консольний додаток, який:

- створює та ініціалізує змінну типу String;
- використовує рефлексію для зміни значення створеного рядка.
- Рядок повинен бути створеним та проініціалізованим двома способами:
    - як строковий літерал;
    - введений набором з клавіатури.
- Значення для заміни може бути задано програмно або введено набором з клавіатури.
- Рядок повинен бути виведений до зміни та після.

## Завдання 2:

**Робота з системою логування**

Відкрийте код 3-ї лаби [Task 3 Simple OOP](https://github.com/lestaplus/java-labs/tree/main/lab3) і внесіть наступні
зміни:

- додайте систему логування для фіксації ходу виконання програми та виведення повідомлень про помилки в консоль;
- додайте вивід повідомлень в текстовий файл.

## Завдання 3:

**Робота з інтернаціоналізацією**

До попереднього завдання [Task 3 Simple OOP](https://github.com/lestaplus/java-labs/tree/main/lab3) - додайте в меню
пункт «Вибір мови» для можливості відображення інтерфейсу взаємодії з користувачем на інших мовах.

Вимоги:

1. Використовуйте клас ResourceBundle для організації інтернаціонального інтерфейсу.
2. Додайте в теку `resources` теку `location`, в якій і розмістіть файли з даними для різних мов.

## Інструкція з локального запуску:

1. Склонуйте репозиторій

```bash
git clone https://github.com/lestaplus/java-labs.git
```

2. Перейдіть до теки лабораторної роботи

```bash
cd java-labs/lab10
```

3. Скомпілюйте проєкт за допомогою Maven

```bash
mvn clean compile
```

4. Запустіть програму

```bash
java --add-opens java.base/java.lang=ALL-UNNAMED -cp target/classes Reflection
```
