# Лабораторна робота №5: I/O Streams

## Завдання:

1. Напишіть програму, яка отримає рядок з максимальною кількістю слів із заданого файлу.
2. Відкрийте код додатка за завданням [Task 3 Simple OOP](https://github.com/lestaplus/java-labs/tree/main/lab3) і внесіть наступні зміни
   - додайте в меню команду для збереження набору об'єктів в файл;
   - передбачте можливість читання набору об'єктів з файлу.
3. Зашифрувати вхідний символьний потік за наступним алгоритмом: замінити кожний символ на такий, код якого більший на значення коду ключового символу. При виконанні завдання:
   1. Реалізувати метод, який реалізує шифрування.
   2. Реалізувати метод, який реалізує дешифрування.
   3. Використати для розв’язання задачі потоки типу FilterOutputStream-FilterInputStream/FilterWriter-FilterReader.
4. Підрахувати частоту, з якою зустрічаються теги на сторінці по URL.
   1. Вивести результати наступним чином: в порядку зростання для тегів в лексикографічному порядку.
   2. Вивести результати наступним чином: в порядку зростання по частоті появи тегів.

## Інструкція з локального запуску:

1. Склонуйте репозиторій
```bash
git clone https://github.com/lestaplus/java-labs.git
```

2. Перейдіть до кореня проєкту
```bash
cd java-labs/lab5
```

3. Скомпілюйте та запустіть програму
```bash
cd src/main/java
javac *.java
java Main
```
